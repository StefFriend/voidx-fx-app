MIDI mappings
Wireless: needs the Bluetooth connection (Chocolate in "Manufacturer Control" mode: A, B, C, D = CC 20–23). Wired: the MIDI IN jack (TRS type A) always works, with the same mappings. "Learn" assigns the next message received.
Presets
Assign blocks
Each switch of the Chocolate (Manufacturer Control: A, B, C, D = CC 20–23) switches on and off the blocks you pick here, one or more. With more blocks, a press follows the first one: they all go on or all go off together.
Chain order
Move any block anywhere, also across the amp. Blocks before the amp run in mono. The pedal checks the DSP before accepting a new order.
